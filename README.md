# Paradise Nursery

Paradise Nursery is a React-based front-end shopping application for browsing and purchasing houseplants.

## Project Overview

The application provides three main pages:

* **Home** – Introduction to Paradise Nursery with a background image and Get Started button.
* **Plants** – Browse houseplants organized into different categories and add them to the shopping cart.
* **Cart** – View selected plants, adjust quantities, remove items, view totals, and proceed toward checkout.

## Features

* Responsive landing page
* Houseplants organized into three categories
* 18 houseplants available for purchase
* Plant images, names, and prices
* Add to Cart functionality
* Dynamic shopping cart count
* Increase and decrease item quantities
* Delete items from the cart
* Automatic total cost calculation
* Continue Shopping functionality
* Checkout button with Coming Soon message
* Redux Toolkit for cart state management
* React Router for page navigation

## Technologies Used

* React
* Vite
* React Router
* Redux Toolkit
* React Redux
* JavaScript
* CSS

## Pages

### Home

The landing page introduces Paradise Nursery and provides a Get Started button that navigates to the plant listing page.

### Plants

The product listing page displays plants under:

1. Air Purifying
2. Aromatic
3. Decorative

Each plant includes an image, name, price, and Add to Cart button.

### Cart

The shopping cart displays:

* Plant image
* Plant name
* Unit price
* Quantity
* Item total
* Increase quantity button
* Decrease quantity button
* Delete button
* Total number of plants
* Total cart cost

## Redux

Redux Toolkit manages the shopping cart state.

The cart supports:

* Adding plants
* Increasing quantity
* Decreasing quantity
* Removing plants
